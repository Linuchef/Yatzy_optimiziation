# Yatzy Strategies

![PyPI version](https://img.shields.io/pypi/v/python-boilerplate.svg)
[![Documentation Status](https://readthedocs.org/projects/python-boilerplate/badge/?version=latest)](https://python-boilerplate.readthedocs.io/en/latest/?version=latest)

This project is looking into finding the optimal choices when playing forced yatzy using dynamic programming. Additionally, we simulate n yatzy games playing optimally and compare the average point score with the exact point score usng the algorithm. Analysis.ipynb needs to be run in order to look at the final table of optimal holds and throws. The code needs to be more polished as it may be a little confusing, but everthing runs as it should. 

There might be some problems with making sure everything works (I am trying my best :)), but I recommend installing all packages in requirements.txt, and the dependencies in pyproject.toml. I will make sure that copying the repo will not entail a lot of problems in the near future.
